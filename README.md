# نظام إدارة محل أجهزة منزلية

نظام شامل لإدارة محلات الأجهزة المنزلية يعمل بشكل كامل أوفلاين على XAMPP، مصمم بواجهة عربية بسيطة وسهلة الاستخدام.

## 📋 المميزات الرئيسية

### ✅ إدارة الأصناف
- إضافة وتعديل وحذف الأصناف
- رفع صور للمنتجات
- تتبع المخزون تلقائياً
- تنبيهات عند انخفاض المخزون
- البحث السريع بالكود أو الاسم

### ✅ إدارة الموردين
- تسجيل بيانات الموردين
- جدولة أيام زيارات الموردين
- تنبيهات يومية للموردين المتوقع قدومهم
- فواتير شراء مع تحديث المخزون تلقائياً

### ✅ إدارة العملاء
- تسجيل بيانات العملاء
- **دعم العملاء غير المسجلين** (إدخال الاسم ورقم التليفون مباشرة)
- متابعة حسابات العملاء
- نظام الأقساط الكامل

### ✅ نظام الفواتير
- **فواتير مبيعات ومشتريات**
- **رأس فاتورة يحتوي على اسم المحل واللوجو والبيانات**
- تعديل الأسعار داخل الفاتورة (لا يؤثر على السعر الأصلي)
- طرق دفع متعددة (كاش، أقساط، انستاباي، فودافون كاش، فيزا)
- طباعة احترافية (A4 أو طابعة حرارية)
- حفظ تلقائي وتحديث المخزون

### ✅ نظام الأقساط
- إنشاء خطط تقسيط مرنة
- تتبع الدفعات
- تنبيهات يومية للأقساط المستحقة
- تسجيل المدفوعات

### ✅ التقارير
- تقرير المخزون
- تقرير المبيعات (بفترة زمنية)
- تقرير الأرباح
- تقرير الأقساط
- تقرير الحسابات
- تصدير PDF لجميع التقارير

### ✅ النسخ الاحتياطي
- نسخ احتياطي تلقائي
- نسخ احتياطي يدوي
- تحميل النسخ الاحتياطية
- استعادة سهلة

### ✅ التنبيهات الذكية
- 🔔 تنبيه صوتي ومرئي عند انخفاض المخزون
- 📦 تذكير بالموردين المتوقع قدومهم غداً
- 💰 تنبيه بالأقساط المستحقة اليوم

## 🚀 التثبيت والإعداد

### المتطلبات
- XAMPP (Apache + MySQL + PHP)
- متصفح ويب حديث (Chrome, Firefox, Edge)
- نظام Windows

### خطوات التثبيت

#### 1. تثبيت XAMPP
- حمّل XAMPP من الموقع الرسمي: https://www.apachefriends.org/
- ثبّت XAMPP في المسار الافتراضي `C:\xampp`
- شغّل XAMPP Control Panel

#### 2. تشغيل الخوادم
- افتح XAMPP Control Panel
- اضغط "Start" بجانب Apache
- اضغط "Start" بجانب MySQL
- تأكد من ظهور اللون الأخضر بجانبهما

#### 3. إنشاء قاعدة البيانات
- افتح المتصفح واذهب إلى: `http://localhost/phpmyadmin`
- اضغط "New" لإنشاء قاعدة بيانات جديدة
- اكتب اسم القاعدة: `store_management`
- اختر Collation: `utf8mb4_unicode_ci`
- اضغط "Create"

#### 4. استيراد الجداول
- اختر قاعدة البيانات `store_management`
- اضغط على تبويب "Import"
- اضغط "Choose File" واختر الملف:
  ```
  C:\xampp\htdocs\سيستم اجهزه منزليه\database\schema.sql
  ```
- اضغط "Go" في الأسفل
- انتظر حتى تظهر رسالة النجاح

#### 5. استيراد البيانات التجريبية (اختياري)
- في نفس الصفحة، اضغط "Import" مرة أخرى
- اختر الملف:
  ```
  C:\xampp\htdocs\سيستم اجهزه منزليه\database\sample_data.sql
  ```
- اضغط "Go"

#### 6. تشغيل النظام
- افتح المتصفح واذهب إلى:
  ```
  http://localhost/سيستم اجهزه منزليه/
  ```
- ستظهر لك الصفحة الرئيسية للنظام

## 📖 دليل الاستخدام السريع

### إضافة صنف جديد
1. من القائمة الرئيسية، اضغط "الأصناف"
2. اضغط "+ إضافة صنف جديد"
3. املأ البيانات (الكود، الاسم، السعر، الكمية)
4. يمكنك رفع صورة للصنف
5. اضغط "حفظ الصنف"

### إنشاء فاتورة بيع
1. من الصفحة الرئيسية، اضغط "فاتورة بيع جديدة"
2. **اختر عميل مسجل أو أدخل بيانات عميل جديد (الاسم والتليفون)**
3. ابحث عن الأصناف وأضفها للفاتورة
4. يمكنك تعديل السعر لأي صنف داخل الفاتورة
5. أدخل المبلغ المدفوع وطريقة الدفع
6. اضغط "حفظ وطباعة"

### عرض التقارير
1. من القائمة، اضغط "التقارير"
2. اختر نوع التقرير المطلوب
3. حدد الفترة الزمنية (إن وجدت)
4. اضغط "عرض التقرير"
5. يمكنك تصدير التقرير كـ PDF

### عمل نسخة احتياطية
1. من القائمة، اضغط "الإعدادات"
2. اضغط "النسخ الاحتياطي"
3. اضغط "إنشاء نسخة احتياطية جديدة"
4. يمكنك تحميل النسخة على جهازك

## ⚙️ الإعدادات الأساسية

### إعداد معلومات المحل
1. اذهب إلى "الإعدادات"
2. أدخل:
   - اسم المحل
   - العنوان
   - رقم التليفون
   - ارفع شعار المحل (Logo)
3. اضغط "حفظ الإعدادات"

**ملاحظة:** هذه المعلومات ستظهر في رأس كل فاتورة

### إعداد الطابعة
- للطباعة على A4: استخدم الطباعة العادية (Ctrl+P)
- للطباعة الحرارية: اختر الطابعة الحرارية من قائمة الطباعة
- يمكنك تعديل حجم الورق من إعدادات الطباعة

## 🔧 حل المشاكل الشائعة

### المشكلة: لا يفتح النظام
**الحل:**
- تأكد من تشغيل Apache و MySQL من XAMPP
- تأكد من كتابة الرابط بشكل صحيح
- جرب: `http://localhost/سيستم اجهزه منزليه/`

### المشكلة: خطأ في الاتصال بقاعدة البيانات
**الحل:**
- تأكد من تشغيل MySQL
- تأكد من إنشاء قاعدة البيانات `store_management`
- تأكد من استيراد ملف `schema.sql`

### المشكلة: الحروف العربية تظهر رموز غريبة
**الحل:**
- تأكد من اختيار `utf8mb4_unicode_ci` عند إنشاء القاعدة
- أعد استيراد ملف schema.sql

### المشكلة: لا تعمل الصور
**الحل:**
- تأكد من وجود مجلد `assets/uploads/products/`
- تأكد من صلاحيات الكتابة على المجلد

## 💡 نصائح مهمة

1. **النسخ الاحتياطي:** اعمل نسخة احتياطية يومياً
2. **الأمان:** النظام مصمم للاستخدام المحلي فقط (لا تعرضه على الإنترنت)
3. **التحديثات:** احتفظ بنسخة من الملفات الأصلية قبل أي تعديل
4. **الصور:** لا ترفع صور كبيرة جداً (الحد الأقصى 5 ميجا)
5. **المخزون:** راجع تنبيهات المخزون يومياً
